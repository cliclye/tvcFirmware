ON THE PAD · ONLY WHILE IDLE

Board tools

locked

These ask the board for data. They work only while it reports IDLE; in any other state the board ignores them and Studio won't send them. Nothing here can arm, fire, move a servo or start a launch.

TVC GIMBAL TEST

Move and align the mount

—

Hold a slider to move the gimbal; let go and it centres. Servos A and B only, never the parachute servo. The test ends by itself within 1 s if the link drops, and the moment the board leaves IDLE.

Alignment trim

Nudge each centre until the motor points straight along the body. The trim is temporary (cleared when the board leaves IDLE or restarts): save it to Rocket setup, then build and install over USB-C to make it permanent.

Servo A0 µs
Servo B0 µs

"Save trim to the board" makes the trimmed position the new centre right away: it's stored on the board's SD card, read back to check it, and kept until you install firmware again (Rocket setup is updated too, so the next install keeps it).

OVER THE RADIO · ONLY WHILE IDLE

Board settings

—

Tune the gains, the TVC centres and the recovery timing without a cable. Studio sends them, the board checks the ranges, stores them on its SD card, reads them back and echoes them, and Studio compares every value. Wiring (channels, directions, endpoints, nose axis) still changes only by installing over USB-C. Installing firmware again replaces anything sent here.

GROUND TEST · TEST LOAD ONLY

Pyro channel test

—

Checks a pyro channel with a test load (an LED with a 1 kΩ resistor, or a small bulb) on the terminal, before any igniter goes near it. Only while the rocket is IDLE and not armed. Two steps: the board gives a one-off code, then fires one short pulse. While the pyro outputs are locked in the firmware the test runs but the pin stays off, and Studio tells you so.

        The workflow

        The sidebar follows this order: Design the rocket, Test it in the simulator and on the board, then Fly and read the logs.

        1. Design → Rocket setup. Enter your servos, endpoints, parts and the TVC linkage (measure with calipers), and estimate apogee. Save. The Tuning lab is a quick 1-axis playground for gains.
        2. Test → 3D flight sim. Run flights and 40 random flights with your real numbers; Fly live lets you kick, gust or steer it.
        3. Test → Board → Install firmware, or the ◎ Sensor test button first: it checks every sensor and logs them to the SD card.
        4. Install the bench image and check the nose axis and the tilt test: when the nose leans one way, the nozzle must swing the opposite way. Use Live → Pad tools with a USB-UART, or record on the SD card and use Replay in 3D in Flight logs. Fix channels and directions in Rocket setup, save, reinstall.
        5. Fly → Launch checklist: finish the bench section, then install the flight image.
        6. At the pad: power on, hands off. Solid green and a chirp every second means ARMED. Red, or a long beep every 2 s, means don't launch.
        7. Fly → Flight logs: put the SD card in your Mac, read or save every session, see the graphs, and Replay in 3D.

        Safety

        Use 2S LiPo only (the servo rail is a linear 5 V regulator). Never connect pyro channel P2. Pyro outputs ship locked: an ejection charge on P1/P3 only fires after the pyro bench test in docs/flight-guide.md (test load first, never a real igniter) and a deliberate unlock in easytvc_safety.h. Nothing here has flown before your first flight, so treat it as a test flight: clear area, low wind, a stand that holds the rocket vertical.

        Tools you'll need on the Mac

        brew install cmake dfu-util. The ARM compiler is in the project's .tools folder.
